# ドキュメント

このディレクトリには、実装時に判断が必要な設計と運用だけを記載します。コードと設定ファイルを唯一の基準とし、文書には判断理由と運用上重要な挙動を記載します。

## 構成

| 文書                                      | 責務                                     |
| ----------------------------------------- | ---------------------------------------- |
| [Architecture](./architecture.md)         | ディレクトリの役割、依存方向、境界       |
| [Component Design](./component-design.md) | コンポーネント分割と状態所有の判断基準   |
| [Development](./development.md)           | ローカル開発、パッケージ管理、静的検査   |
| [Testing](./testing.md)                   | Unit、Component、E2Eの分担               |
| [Repository](./repository.md)             | CI、依存関係の更新、GitHubリポジトリ設定 |
| [AGENTS.md](../AGENTS.md)                 | AIエージェントが実装時に守る規約         |

## 更新方針

実装を変えた場合は、該当する文書だけを更新します。導入ライブラリごとに文書を増やさず、設計や運用の責務に合わせて追記してください。
